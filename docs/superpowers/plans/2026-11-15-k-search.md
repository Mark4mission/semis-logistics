# K드라이브 찾기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** H:drive 통합 검색 · 아르고에서 K드라이브 '항공보안' 아래 파일 · 폴더의 위치를 찾고(이름 · 폴더 경로 · 날짜, 문장 · 연도 표현까지), 위치 복사 또는 H 문서 열기로 이어 준다.

**Architecture:** Mac 에이전트가 하루 한 번 '항공보안' 을 읽기만으로 걸어 이름 · 크기 · 날짜 줄을 Edge `semis-logi-ksync` 새 동작 `kidx` 로 보내고, SQL 이 비공개 표에 덧쓴다(`first_seen` 유지). 브라우저는 3등급 이상일 때 읽기 RPC 로 목록을 한 번 받아 메모리에 두고(`js/kidx.js`), 통합 검색의 'K드라이브' 묶음 · K 위치 창 · 아르고 `argos_find scope: kdrive` 가 그 목록을 쓴다.

**Tech Stack:** 바닐라 JS(정적 웹앱, jsdom 시험) · Supabase Postgres(plpgsql, PGlite 시험) · Deno Edge Functions · Node ≥ 20 에이전트(npm 의존성 없음).

**Spec:** `docs/superpowers/specs/2026-11-15-k-search-design.md` (Mark 승인 11-15) — 각 Task 는 spec 의 § 를 근거로 한다. 구현자는 둘 다 읽는다.
