# K드라이브 찾기 — 설계 (2026-11-15, 구현 전)

> 공개 저장소 문서다. 서버 주소 · IP · 계정 · 사람 이름 · 실제 K 파일 이름은 적지 않는다(HANDOFF §6). 폴더 번호 · 업무 이름(예: `80 개인정보` · `99 보관`)은 이미 `docs/KSYNC.md` 에 있는 수준까지만.
> `(내 판단)` = 설계자가 정한 것(Mark 확인 전). 표시 없는 것 = Mark 가 대화에서 정한 것.

## 1. 왜

Mark 의 실제 사례: 작년 국토부 항공안전 점검 자료를 찾으려고 K드라이브 `04 수검·심사` 를 뒤졌는데, 그 자료는 '보안 외' 라서 `70 안전` 쪽에 있었다. 반대로 AEO 점검 자료는 기억대로 04 에 있어 금방 찾았다. 찾은 파일은 열어서 올해 수검에 참고하려 했다.

- **K 폴더 구조가 사람의 머릿속 분류와 어긋날 때 길잡이**가 필요하다. 사람은 파일 이름이 아니라 **주제 + 때**('작년 국토부 안전 점검')로 찾는다.
- 찾은 다음 할 일은 **그 파일 · 그 폴더를 여는 것**이다.
- 동료(50대)는 처음엔 메뉴(예: 점검·교육)를 눌러 찾고, 없으면 다른 메뉴 → 검색칸에 질문 → 익숙해지면 아르고. Mark 예상: 몇 번 써서 쓸모를 알면 메뉴보다 검색 · 아르고를 많이 쓴다. → **처음 몇 번의 결과가 좋아야 한다.**

## 2. 목표 · 비목표 · 안 되는 것

**목표**
1. H:drive 통합 검색에서 K드라이브 '항공보안' 아래 **파일과 폴더의 위치**를 찾는다(이름 · 폴더 경로 · 날짜로).
2. 결과에서 **바로 열 수 있는 데까지** 간다 — K 폴더 위치 복사(윈도 탐색기 주소창에 붙여 넣기), H 에도 올라간 파일이면 H 에서 바로 열기.
3. 낱말 일치를 넘어 **맥락**으로도 찾는다 — 검색칸은 문장 · 연도 표현 · 조사를 견디고, 아르고는 자연어 질문을 여러 검색어로 바꿔 후보 중에서 골라 위치와 이유를 말한다.
4. 메뉴 습관에서 검색으로 가는 **다리** — 문서함에서 못 찾으면 같은 말로 K드라이브를 찾아보게 한다.

**비목표(이번 범위 밖)**
- 파일 **내용** 색인 · 내용 검색. SSI 원문을 외부 API 로 보내지 않는 원칙이 있고, SMB 로 8.4GB 를 읽어야 한다. 필요하면 SSI 아닌 폴더만 따로 검토.
- 뜻을 숫자로 바꿔 찾는 새 AI 색인(임베딩 인프라) `(내 판단)` — 비용 · SSI 원칙. 써 보고 부족하면 다시 본다.
- K 에 쓰기(어떤 형태로도). K 는 읽기만 한다 — K 에는 휴지통이 없다.
- 새 K 폴더 알림 · H 분류 추천 — **Mark 가 하기로 했고 "새 폴더를 놓치지 말고 꼭 알려 달라"고 했다.** 다만 동기화 쪽 일이라 이 작업 **다음 차례로 따로** 한다(§11). 이번 색인이 그 바탕이 되도록 폴더 줄도 함께 모은다.
- H 정보(일정 · 교육 기록 · 지적사항 · 회의록)를 K 에 파일로 내보내기 — Mark: 알맞은 단계에서 새로 설계.

**안 되는 것(돌아가도 실패)**
- 권한 밖 사람(협력업체 · 서명 세션 · 등급 미달)에게 K 파일 이름이 보이는 것 — K 에는 SSI 폴더 · 개인정보 폴더가 있다.
- 검색이 느려지거나, 검색칸 입력 중 한글 조합이 깨지는 것(HANDOFF §6-11).
- K 결과가 H 결과를 밀어내 평소 검색이 나빠지는 것.
- 위치 복사가 엉뚱한 경로를 주는 것(서버 주소를 코드에 박아 두어 바뀌면 틀어짐 등).

## 5. 색인 — Mac 에이전트(`tools/ksync`)

- **언제**: 회차(매일 · 수동 · `--once`)가 연결 동기화 · 미리보기 건수 · 해시 채우기를 마친 **뒤** 하루 한 번(`st.kidxDay !== today`, 폴더 목록 보고와 같은 방식 — 색인 뿌리가 바뀌었으면(`st.kidxRoot !== root`) 그날 이미 걸었어도 다시 `(구현에서 고침)`). 동기화 결과와 무관하게 돈다(동기화가 일부 실패해도 색인은 시도). `--dry-run` 은 걷기만 하고 보내지 않으며 개수 · 걸린 시간만 출력 `(내 판단)`.
- **설정은 hello full 로 받는다**: `kidx: { on, root, excludes }`. `on` 이 거짓이거나 `root` 가 비면 걷지 않는다.
- **무엇을**: `root`(공유 뿌리 기준 '항공보안' 경로) 아래 전부 — 파일 줄(상대 경로 · 크기 · 수정 시각)과 폴더 줄(상대 경로). **내용은 열지 않는다**(readdir · lstat 만, 해시 없음).
- **빼는 것**: 동기화 색인과 같은 이름 규칙(`plan.mjs` `excluded()` — `~$*` · 숨김 · `Thumbs.db` · `_H드라이브_*` · 충돌 사본 등) · 링크(따라가지 않음) · `kidx.excludes`(뿌리 안 경로, 대소문자 무시 — 그 아래를 걷지도 않음).
- **동기화의 전체 지정 제외(`ksync_state.excludes`)는 따르지 않는다** `(내 판단)` — 그 목록은 'H 로 올리지 않음'(저장소 · 개인정보)이고, 찾기의 '보이지 않음'과 뜻이 다르다(예: `99 보관` 은 올리지는 않아도 찾을 수는 있어야 함). 찾기에서 숨길 것은 `kidx.excludes` 하나로만 정한다.
- **동시 4개**로 폴더 읽기 · lstat 을 돌린다(측정 §3). 상한: 줄 5만 · 30분 — 넘으면 보내지 않고 기존 색인을 그대로 둔다(기록에 한 줄). 상한에 닿은 걷기도 **그날의 걷기로 친다**(그날 다시 걷지 않음 — 몇 분 사이 나무는 줄지 않으니 수동 요청 회차마다 30분씩 걷지 않게. 보내기 실패만 그날 다음 회차에 다시). 깊이 20 을 넘는 폴더는 보내기 전체를 멈추지 않고 그 폴더만 `err` 로 보낸다(그 아래 옛 줄은 서버가 남김) `(구현에서 고침)`.
- **못 읽은 폴더**는 `err` 목록(최대 200)으로 끝 보고에 싣는다 → 서버가 그 아래 옛 줄을 지우지 않고 둔다(일시적 SMB 오류로 색인이 비지 않게).
- **보내기**: Edge `kidx` 동작 — `begin` → `rows`(한 번에 2,000줄 이하, 약 0.6MB — 본문 상한 2MB 안) × N → `end { n, err }`. 6,500줄이면 호출 5~6번(분당 300 한도와 무관). 덩어리는 줄 수와 함께 약 700KB 로도 자르고(긴 한글 경로 2,000줄은 2MB 에 닿을 수 있음), 서버가 거절할 경로(300자 넘음 등)는 보내지 않고 기록에 센다 — `n` = 보낸 줄 `(구현에서 고침)`.
- 에이전트 판 1.73.0(Mac `install.sh` 다시 실행 필요).

## 6. 서버 — SQL(`tools/sql/semis-logi-ksync.sql`) · Edge

- **설정**: `ksync_state.kidx jsonb` — `{ on: false, root: "", excludes: [], win_root: "" }`(Mark: `99 보관` · `80 개인정보` 모두 넣음 → 뺄 폴더 기본 없음). `win_root` = 윈도에서 '항공보안' 폴더를 가리키는 경로 앞부분 — Mark: 동료 PC 의 드라이브 문자가 같은지 모름 → **서버 경로**(`\\<서버>\<공유>\…\항공보안`, 사내망 어느 PC 에서나 열림). 실제 값은 운영 DB 에만, 코드 · 문서에 넣지 않음. 관리 RPC `semis_logi_ksync_kidx_save(p)`(시스템관리자, `ksync_admin()`): `root` · `excludes`(20개 이하) = `ksync_rel` 검사(`excludes` 는 동기화 지정 제외와 같은 `ksync_excl` — 앞뒤 공백 떼기 · 대소문자만 다른 것은 하나로 `(구현에서 고침)`), `win_root` = 120자 이하 · 제어 문자 없음 · `X:\` 또는 `\\` 로 시작. `root` 가 바뀌면(대소문자 무시) 같은 저장에서 `kidx` · 받는 중 표 · `kidx_last` 를 비운다(옛 뿌리 경로가 새 경로 앞부분과 함께 보이지 않게 — 걷던 `end` 는 `bad`) `(구현에서 고침)`. 상태 RPC 에 `kidx { on, root, excludes, win_root, at, n_files, n_dirs, ms, err }`.
- **표**: `semis_logi_private.kidx(path text primary key, is_dir boolean, size bigint, mtime timestamptz, first_seen timestamptz, seen_at timestamptz)` · 받는 중 표 `kidx_stage`(path · is_dir · size · mtime + agent_id). 둘 다 RLS 켜고 public · anon · authenticated 권한 없음(기존 ksync 표와 같게).
- **`first_seen` 을 이번부터 남긴다** `(내 판단)` — §11 의 '새 폴더를 놓치지 않고 알림'이 이번 배포와 그 작업 사이에 생긴 폴더까지 알 수 있게. 그래서 `end` 는 통째 바꾸기가 아니라 **덧쓰기**다: 있는 줄은 크기 · 날짜 · `seen_at` 만 고치고 `first_seen` 은 그대로, 새 줄은 `first_seen = now()`, 이번에 안 보인 줄은 지움(`err` 폴더 아래는 남김). 첫 색인의 줄은 모두 `first_seen` = 첫 색인 시각(그날을 기준선으로 본다).
- **에이전트 동작 `kidx`**(입구 `semis_logi_ksync_agent` 의 허용 목록에 추가 · `ksync_auth` 그대로): `begin` = 그 에이전트의 stage 비움 · `rows` = 줄마다 `ksync_rel` 통과 · `excludes` 아래 아님 · 크기 숫자일 때만 stage 에 넣고 `{ accepted, rejected }` 를 돌려줌(서버도 거절 수를 더해 둠) · `end { n }` = stage 줄 수 + 거절 수가 보낸 줄 수 `n` 과 같을 때만 한 트랜잭션으로 덧쓰기 → `at` · 개수 · 거절 수 · 걸린 시간 기록, stage 비움. 다르면(덩어리를 잃음) 바꾸지 않고 `bad`. 잘못된 줄 몇 개 때문에 색인 전체가 거절되지 않게 한다. 한 걷기에 받는 줄은 6만까지(넘게 될 `rows` 는 `bad`), 색인에 파일이 있는데 받은 파일이 하나도 없으면 바꾸지 않고 `empty`(Edge 409 — 빈 것처럼 보이는 마운트가 `first_seen` 을 모두 새로 매기지 않게) `(구현에서 고침)`.
- **읽기 RPC `semis_logi_kidx_list()`**: `rank_now() >= 3`(서버 기준 — 협력업체는 1, 서명 세션은 0) 아니면 42501. `on` 이 거짓이면 `{ ok, on: false }`. 돌려주는 것: `{ ok, on, at, win_root, dirs: [경로…], files: [[폴더 번호, 이름, 크기, 'YYYY-MM-DD', H 문서 id | null]] }` — 읽을 때도 `excludes` 아래는 다시 거른다(설정을 바꾸면 다음 걷기 전이라도 바로 숨음). 'H 에도 있음' = 활성 연결의 기준선(`ksync_files.state = 'ok'`, `lower(m.k_path || '/' || f.rel_path) = lower(root || '/' || path)`)의 `doc_id`.
- 크기 추정: 99 보관 포함 약 1MB(압축 전송 약 0.2~0.3MB), 빼면 약 0.3MB.
- **Edge `semis-logi-ksync`**: `ACTS` 에 `kidx` 추가 · 그대로 SQL 로 넘김(재배포 필요). 다른 동작은 그대로.
- 마이그레이션 이름 `semis_logi_security_37_ksync_kidx` `(내 판단 — 동기화 v2 설계의 37 · 38 예정 번호는 다음 번호로 밀림)`. 이 SQL 파일 전체 다시 실행 = 기존 관례.

## 7. 검색칸(`js/search.js` · 새 `js/kidx.js`)

**모양 — Mark 선택 A '한 목록에 함께'**: H 결과 아래에 묶음 `K드라이브`(종류 꼬리표 `K폴더` · `K파일`). 다른 묶음처럼 4건 보이고 'N건 더 보기'.

- `js/kidx.js`(`SemisKidx`): 목록을 처음 필요할 때(검색 패널을 열 때 · 아르고가 찾을 때) 한 번 받아 **메모리에만** 둔다(localStorage 금지 — 같이 쓰는 PC). 30분 지나면 다음에 열 때 다시 받음 `(내 판단)`. 받는 동안 묶음 자리에 '불러오는 중' 한 줄, 다 받으면 열린 패널을 다시 그린다(검색칸 노드는 그대로 — §6-11).
- 프로바이더: `id: "kdrive"`, `minRank: 3`, `module` 없음 → 협력업체는 `canUseProvider` 에서 이미 빠지고, 서버 RPC 도 막는다(이중). 항목은 폴더 · 파일 둘 다. 항목마다 **경로로 만든 고정 id**(예: 경로 해시 앞 10자 — 다시 받아도 같은 파일은 같은 id)와 **빈 route**(`route: ""` — 지정하지 않으면 검색이 `dashboard` 로 보낸다), 누르면 `pick` 이 §8 의 위치 창을 연다.
- **결과를 누를 때 화면 문서함에 넘기는 검색어**(H 문서 결과 · 위치 창의 'H:drive 에서 바로 열기' 모두): 사용자가 친 글 그대로가 아니라 **그 결과에 실제로 맞은 낱말**(군말을 뺀 · 조사를 뗀 · 연도로 바꾼 꼴) `(내 판단)`. 문서함 자체 거르기(`docshelf.js` `termsOf`/`hits` — 낱말 그대로 모두 포함)는 바꾸지 않는다. 그래야 "작년 국토부 점검 자료 찾아줘"로 찾은 문서를 눌렀을 때 문서함이 비지 않는다(지금도 동의어로 찾은 결과는 같은 문제가 있어 `aka` 로 피해 왔다 — HANDOFF §6-26). 맞은 낱말은 `scoreOf` 가 알고 있으니 그 결과에 실어 둔다.
  - 파일: 제목 = 파일 이름, 아래 줄 = `폴더 › 폴더 › 폴더 · 날짜`, 찾는 글 = 이름 + **폴더 경로 전체**(그래서 파일 이름에 없는 '국토부'도 폴더 이름으로 맞음).
  - 폴더: 제목 = 폴더 이름, 아래 줄 = `위 폴더 경로 · 파일 N개`(바로 아래 파일 수).
  - 같은 점수면 최근 날짜가 위 `(내 판단)`. 묶음 상한은 기존 `GROUP_MAX` 그대로.
  - 7,900 항목을 매 입력(120ms 늦춤)마다 훑는다 — 찾는 글(소문자)은 받을 때 한 번 만들어 둔다. 보통 노트북에서 한 번 훑기 50ms 이하.
- **문장 · 때 표현 견디기** `(내 판단 — 모든 묶음에 적용, 기존 결과는 넓어지기만 함)`:
  - 군말 빼기: `어디 · 어디에 · 있어 · 있나요 · 있는지 · 찾아 · 찾아줘 · 알려줘 · 보여줘 · 좀 · 관련 · 자료 · 파일 · 문서` 등 — 다른 낱말이 하나라도 남을 때만 뺀다.
  - 조사 뗀 꼴도 함께: 낱말 끝 `은 · 는 · 이 · 가 · 을 · 를 · 의 · 에 · 에서 · 으로 · 로 · 와 · 과 · 도 · 만` 을 뗀 꼴을 대안으로 더한다(뗀 뒤 2글자 이상일 때만 — '회의'가 '회'가 되지 않게).
  - 때: `작년` → 올해−1(한국 시각)의 `2025` · `25년`, `올해` · `재작년` · `내년` 도 같은 식. `2025년` → `2025`.
  - 업무 동의어 보강(`SYN`): 예 국토부 ↔ 국토교통부, 서항청 ↔ 서울지방항공청, 점검표 ↔ 체크리스트, AEO ↔ 수출입안전관리우수업체 등 — 목록은 구현자가 일반 업무 말로 만들고 PR 에서 Mark 가 본다(실제 파일 이름 · 사람 이름 금지).
- 모든 낱말이 맞는 결과가 없으면 지금처럼 '일부만 맞는 결과' + '아르고에게 물어보기'.

## 8. K 위치 창(결과를 누르면 — 검색칸 · 아르고 공통)

브라우저는 보안상 K(SMB) 파일을 직접 열지 못한다(`file://` 막힘). 그래서:

- 작은 창(`openModal`): 이름 · 위치(윈도 경로) · 날짜 · 크기 · 'K 에서 확인: 색인 시각'.
- 주 단추 **[폴더 위치 복사]** — 파일이면 **그 파일이 든 폴더**, 폴더면 그 폴더의 윈도 경로(`win_root + '\' + 경로('/' → '\')`)를 복사 `(내 판단 — 폴더가 열리면 같은 때 자료 묶음을 한눈에 봄)`. 아래 한 줄: '탐색기 주소창에 붙여 넣고(Ctrl+V) Enter'. 복사가 막히면(권한 · 오래된 브라우저) 경로 글자를 선택된 상태로 보여 준다.
- 보조 단추 **[H:drive 에서 바로 열기]** — H 문서 id 가 있고 그 문서가 이 사람에게 보일 때만(문서함 프로바이더와 같은 규칙: 화면 보임 · SSI 는 3등급). 누르면 그 화면으로 가서 문서함을 그 이름으로 거른다(`SemisDocs.pickTo`).
- `win_root` 가 비어 있으면 복사 단추 대신 '관리자가 경로 앞부분을 아직 넣지 않았습니다' + '항공보안 › …' 경로만.

## 9. 아르고(`js/argo.js` · Edge `semis-logi-argo`)

- **모델**: Mark — "똑똑하고 빠른 모델". 지금 Claude Sonnet 5.5(최신 Sonnet) 그대로, **생각 깊이(effort)도 그대로 Sonnet 5.5 기본값 `high`** — 코드에 effort 를 넣지 않는다. 다시 검토한 이유(11-15, Mark 요청): effort 는 K 찾기만이 아니라 아르고의 **모든** 요청(이수증 · 점검 결과 판독 · 지적사항 추출 등 정확도가 중요한 일)에 걸리고, 낮추면 도구 호출 수도 줄어 'K 를 여러 검색어로 2~4번 찾기'와 어긋난다. `xhigh` · `max` 는 긴 코딩 · 장시간 자율 작업용이라 짧은 대화에는 기다림 · 비용만 늘린다. 운영 적용 뒤 실제 위치 질문 5개로 속도 · 정확도를 보고, 느리면 그때 `medium` 을 시험해 정한다(§14). 검색칸 자체는 AI 를 쓰지 않는다(즉시 · 비용 없음).
- **`argos_find` 에 `scope`**: `all`(기본 — **지금과 같음, K 는 넣지 않음**) · `kdrive`(K 만, 최대 30건) `(내 판단 — K 이름은 위치를 묻는 질문일 때만 모델로 간다. 평소 찾기마다 K 이름이 따라가지 않게)`. K 항목 = `{ kind: "folder"|"file", name, folder: "…›…", date, in_h, go: "k/<고정 id>" }`. 등급 미달이면 빈 목록과 한 줄 안내(오류 아님).
- **도구 설명 · 지침**: "K드라이브(공유 폴더 '항공보안')의 파일 · 폴더 이름과 위치를 찾는다(내용은 모름). 질문이 문장이면 핵심 낱말 · 동의어 · 연도(작년 → 연도 숫자)로 바꿔 scope kdrive 로 2~4번 부르고, 후보 중 질문에 맞는 것을 골라 **폴더 경로로 위치와 그곳에 있는 이유**를 짧게 말하고 [[이름|go]] 를 붙인다. 결과에 없는 위치는 지어내지 않는다."
- **답 속 단추**: `[[이름|k/고정 id]]` → 그 K 항목의 위치 창(§8)을 여는 단추. id 는 경로로 만든 고정 값이라 아르고 대화가 남아 있는 동안 목록을 다시 받아도 같은 파일을 가리킨다. 지금 화면의 K 목록에 그 id 가 있을 때만 단추가 된다(지워졌거나 아직 안 받았으면 굵은 글자). `goOk` 는 `k/…` 를 따로 다룬다.
- 안내 지식(`docs/ARGO-GUIDE.md`)에 한 줄: K드라이브 찾기 · 위치 복사 쓰는 법.

## 12. 보안 · 개인정보

- 보는 사람(Mark): 서버 `rank_now() >= 3` — 안전보안파트 · 시스템관리자(SSI 문서와 같은 선). 협력업체(서버 1) · 서명 세션(0) · 화물팀 관리자(2) · 일반(1)은 검색칸 묶음도, 읽기 RPC 도, 아르고 `kdrive` 결과도 없다.
- 모으는 것: 이름 · 폴더 · 크기 · 날짜만. 내용 · 해시 없음. Mac 에서 서버로만, 화면은 메모리에만.
- 넣는 폴더(Mark): `99 보관` · `80 개인정보` 모두 넣음. `80` 의 파일 이름에는 사람 이름이 있을 수 있다 — 3등급만 보고, 나중에 숨기려면 관리 화면 '뺄 폴더'에 넣으면 읽기에서 바로 빠진다.
- 에이전트 동작 `kidx` 는 기존 키 · 허용 IP · 횟수 제한을 그대로 탄다. 쓸 수 있는 것은 kidx 표뿐(문서함 · 다른 표 불가).
- 아르고(Mark): K 이름을 본다 — 위치를 묻는 질문에서 `scope: kdrive` 를 부를 때만 그 결과(최대 30건 · 이름 · 폴더 경로)가 Anthropic API 로 간다. 지금도 H 의 SSI 문서 제목은 같은 도구로 아르고에 간다(원칙은 '원문을 다루지 않음' — 내용은 가지 않음).
